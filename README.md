### Sobre este desafio
Neste desafio o objetivo é criar um encurtador de URLs completo utilizando os conceitos de Spec-Driven Development via SpecKit

#### O que foi implementado
- Implmentação em C# .NET 10 com Minimal API
- Uso de SpeckKit (ferramenta para auxílio dos artefatos do SDD)

Neste processo eu aprendi:
* Uso do Speckit com SDD
